# 地下商店印象图

本目录保存地下商店布局选型过程中的整幅印象图，仅用于设计评审，不是运行时素材。
Godot 通过上级 `.gdignore` 忽略这些文件，导出预设也排除了 `reports/*`。

最终采用的方向是：沿用现有肉鸽路线顶部 HUD；左侧约三分之一为小葱与矿洞商人
场景；右侧约三分之二为无分类的 5×2 商品网格；卡片内直接显示光石价格；选择
商品后弹出同款物品说明与购买入口；底部只保留退出商店按钮。

这些印象图是整幅 RGB 合成画面，人物、背景、面板、文字和商品已经烘焙在一起，
因此不能直接裁切为正式素材。最终只把右侧面板、标题牌、商品卡状态、按钮和详情框
保留为独立交互 UI；背景与小葱直接复用项目已有素材，不从印象图提取，也不额外生成
商店专用副本。交互素材位于 `resources/texture/rogue_shop/`，对应母稿和处理记录位于
`dev_assets/source_images/rogue_shop/underground_shop/`。
