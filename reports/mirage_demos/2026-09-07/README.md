## 实录方式

所有画面由项目中的实际 Godot 场景录制。片段 01 使用两个真实 ENet LAN 进程自动操作；片段 02 使用自动观察镜头，不代表玩家视野。片段 03–06 是脚本安排起点、固定靶和操作的本地演练，不是两位真人联网对战录像。片段 04 的固定靶在不同试射之间重置回合，画面已注明。

伤害、扣款、库存、换弹、移动碰撞和视野显隐由原有游戏逻辑执行。没有通过修改目标血量、伪造 UI 或替换画面制造结果。演示没有修改生产地图或修复片段 06 中的缺陷。

录像使用 Godot 4.6.3 的 MovieMaker 离线逐帧录制，再编码为 H.264 / AAC MP4。30 fps 是录制设置，不能据此判断实时运行性能。保留游戏声音，未添加解说或音乐。完整合集统一色彩范围并包含六个章节，分辨率没有放大。

## 实际观察结果

- 房间双方通过真实 LAN 进入同一对局，各有一名 CT / T，角色固定为维什戴尔。见 [网络与时序记录](demo-lobby.json)。
- 购买 AK 后，金额从 $4000 变为 $1300；丢出、拾取、切换和换弹均成功，最终 AK 弹药 30 / 87。见 [枪械记录](combat-weapons-result.json)。
- 四次物理命中后的生命值分别为 100 → 75、100 → 0、100 → 80、100 → 0。见 [伤害记录](combat-damage-result.json)。
- 遮挡目标在约 6.18 秒出现，返回后在约 18.02 秒重新隐藏；射线命中 A 点 Default 箱体。见 [显隐记录](demo-vision.json)。
- A1 连续向右移动被卡在 x≈1422.6；试探下方缝隙后仍停在 x≈1424.1。另一段从超市 x=540 实际移动到中路 x≈1070，说明额外直通路线存在。见 [碰撞记录](demo-issues.json)。

六个分段已逐一完整解码检查，无解码错误，无持续至少 0.25 秒的黑屏；关键画面已抽帧检查。完整合集另行验证帧数和完整解码。播放页已检查引用文件、页面结构与脚本语法；应用浏览器的本地文件安全策略阻止了浏览器内播放验证，可直接在本地播放器打开 MP4。
